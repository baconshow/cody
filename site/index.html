Cody

A little desk pet for Claude Code. It reacts to what Claude is doing, and you can talk to it.

Download for Windows Claude Code plugin Source on GitHub

What it does

Types along while Claude edits code, thinks while commands run, finds a bug when a test fails, throws confetti when a long task is done, and dozes off when Claude is closed. Hold it (or say "Cody") and ask anything: your words go into your own Claude Code session, and Cody answers out loud.

Private by default

Cody runs on your computer and uses your own Claude Code. Nothing is sent to its author. Your phone reaches it through your own Tailscale network, never the public internet.
