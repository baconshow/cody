Cody

Bring your Claude Code to life: a desk pet that reacts to what Claude does, takes orders by voice and tells your phone when Claude needs you.

Download for Windows Claude Code plugin Source on GitHub

The pitch

The one part of this page written like a brochure, for a thing that is free and MIT. All of it is real.

  • Bring your Claude Code to life. A desk pet that reacts, live, to every search, edit, command, failed test and permission prompt.
  • Command Claude Code by voice. Say "Cody" from the couch: your words land in a real Claude Code session on your computer, and it answers out loud. Approve commands with a spoken yes or no.
  • Change your own code without the keyboard. "Cody, add a dark mode toggle to the settings page." Claude edits your project, locally, asking first. Quick questions about the code work the same way.
  • Everything you plugged into Claude Code, by voice. Any MCP server you connected answers through Cody, with the same permission prompts.
  • Pass a word to your other Claude sessions. "Cody, tell my other session to run the tests." The voice session can message any other Claude session open on your computer, Claude Desktop included.
  • Keep an eye on every session. A long task done or Claude waiting for you: your phone buzzes with Cody's face, app closed or not. A widget keeps the last heads-up.
  • Know where you stand with your plan. "Cody, how much usage do I have left?": the session and the week, said and shown on screen, with when each resets.
  • A desk buddy on top. Timers, reminders, a memory of how you like things, screenshots straight to WhatsApp, a mini Cody that points at the button you asked about, scenes and skins.
  • Installs in three steps. Download, open Cody, scan the QR code with your phone. The first run sets up the private network and the voice session for you.

What it does

Types along while Claude edits code, thinks while commands run, finds a bug when a test fails, throws confetti when a long task is done, and dozes off when Claude is closed. Hold it (or say "Cody") and ask anything: your words go into your own Claude Code session, and Cody answers out loud.

Private by default

Cody runs on your computer and uses your own Claude Code. Nothing is sent to its author. Your phone reaches it through your own Tailscale network, never the public internet.
